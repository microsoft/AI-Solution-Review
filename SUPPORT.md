# Support

This repository holds the public documentation and the solution file for the **Agent Review
Program** and the **Agent Review Center**. See the [README](README.md) for what the review covers,
what the tool does, and what it requires.

## Where to go for what

| If you want to… | Go here |
|---|---|
| **Request a review for your agent** | Use the [nomination options on the website](https://microsoft.github.io/AI-Solution-Review/#nominate), or ask the Microsoft team you already work with about the Agent Review Program. See [How to get started](README.md#how-to-get-started). |
| **Check whether your agent is a fit** | Ask your Microsoft contact — they will scope it with you beforehand. |
| **Get your tenant ready** | Hand your admin the [prerequisites checklist](guides/prerequisites.md#checklist). |
| **Install or configure the Agent Review Center** | Follow the [install guide](guides/install.md). |
| **Fix a setup or review problem** | Look up the message in [Troubleshooting](guides/troubleshooting.md), and check the [FAQ](guides/faq.md). |
| **Ask how the review works** | [Open an issue](https://github.com/microsoft/AI-Solution-Review/issues/new/choose) in this repository. Questions about what is checked, prerequisites, findings, or data handling are all fair game. |
| **Report an error in these docs** | [Open an issue](https://github.com/microsoft/AI-Solution-Review/issues/new/choose), or send a pull request. See [Contributing](README.md#contributing). |
| **Get help with a live production problem** | Use your normal Microsoft Support channel. This repository is not a support or escalation path, and nobody here is on call. |
| **Get help with the Agent Review Center during an engagement** | Raise it with your Microsoft contact for that engagement. They have the context. |
| **Report a security vulnerability** | Do not open an issue. Follow [SECURITY.md](SECURITY.md). |

## Before you file an issue

- Search the existing issues first so we don't end up with duplicates.
- **Issues in this repository are public.** Do not post customer or tenant data, environment or
  agent identifiers, conversation transcripts, telemetry exports, review results, or screenshots
  containing real data. Describe the question generically instead.

## Response expectations

Issues are answered on a best-effort basis by the team that runs the program. There is no service
level agreement, and response times vary.

## Microsoft Support Policy

Support for the documentation in this repository is limited to the resources listed above.
