Install the Agent Review Center

The Agent Review Center is installed as part of the Copilot Agent Kit, an open-source toolkit for Copilot Studio agents. It goes into a Power Platform environment in your own tenant.

Start this before your first working session. The tenant admin approvals and the transcript setting are the two things most likely to hold up a review, and neither is quick to arrange on the day.

The Copilot Agent Kit documentation refers to the underlying capability as the Agent Review Tool. It is the same thing you will see described here as the Agent Review Center.

Prerequisites

Licensing — tenant level

Tenant-level licensing requirements and why each is needed
RequirementWhy
Copilot Studio license The agents under review run on it.
Power Apps Premium license Required to run the app and the Power Automate cloud flows that use Premium connectors.
Copilot credits Running a review consumes credits. Credits must also be allocated to the environment where the Agent Review Center runs, not only owned at tenant level.

Environment configuration — needs a system administrator

Environment configuration settings and notes
SettingNotes
Dataverse provisioned The environment must have Dataverse as a data store. Configuration and results are stored there.
Not a preview environment Use a standard environment.
Code apps enabled Enable Power Apps Code Apps on the environment.
Power Apps component framework enabled Enable the component framework for canvas apps.
Bot transcripts enabled Required for runtime analysis and conversation analytics. See the note below — turn this on early.
Creator Kit deployed A required dependency. Set up the Creator Kit first.
Connectors allowed by data policy Your environment's data loss prevention policies must permit every connector shipped in the solution, and connections must be populated at import time — regardless of which features you plan to use.

Access and roles

Two environments can be involved: the one where the Agent Review Center runs, and the one where the agent being reviewed lives. They can be the same environment, but they do not have to be.

Access and roles your tenant admin grants, by environment
WhereWhat your tenant admin grants
Environment running the Agent Review Center System administrator to perform the install. For the review owner: a security role that can read the Agent Review Center tables, and direct access to the Agent Review Center code app.
Environment holding the agent under review Agent Maker, so the owner can work on the agent. Bot Transcript Viewer, so conversation transcripts can be read. Transcript access is governed by environment security roles.

Full detail is in the Copilot Agent Kit prerequisites.

Turn on transcripts early

Transcript recording is not retroactive. Nothing is backfilled. If recording is switched on the day before the review starts, there is almost no history to analyze, and the runtime and conversation analysis will have little to say.

Two things to tell your admin:

  • Transcript recording is an environment setting, so it applies to agents in that environment, not only the ones under review. Environment-group policies can override a per-environment setting.
  • Retention is configurable. Check that the retention window covers the period you want reviewed.

After switching it on, run a test conversation and confirm a transcript row actually appears before you rely on it.

Install

  1. Check prerequisites

    Work through Copilot Agent Kit prerequisites before downloading anything.

  2. Install the kit

    From Marketplace, or import the latest managed solution from the GitHub releases. Full steps: Install Copilot Agent Kit.

  3. Configure connection references

    In Power Apps, open the default solution and make sure the Copilot Agent Kit - Dataverse connection reference is valid.

  4. Enable the cloud flows

    In Power Automate, confirm every flow in the solution is on. Enable them in order: flows ending in Grandchild, then Child, then the rest.

  5. Finish in the Setup Wizard

    The kit includes a Setup Wizard for connection references, environment variables, and flows. The Agents (preview) connector used by the review workflow cannot be configured during solution import — skip it at import and complete it in the Setup Wizard.

If you are already scoping a review with your Microsoft contact, they can walk your admin through this. You do not have to get it all working alone before you talk to us.
