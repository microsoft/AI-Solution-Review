# Agent Review Center guides

Customer documentation for installing and using the Agent Review Center. Start with the
[README](../README.md) for an overview of the Agent Review Program.

| Guide | For | What it covers |
|---|---|---|
| [Prerequisites](prerequisites.md) | Power Platform admins, review owners | Licensing, environment settings, transcripts, data policies, and roles — as a checklist you can hand to your admin. |
| [Install](install.md) | System Administrators | Download, import, one-time setup, the readiness checklist, sharing with reviewers, upgrade, and uninstall. |
| [Run a review](run-a-review.md) | Reviewers | Starting a review, reading the results, working through findings, sharing reports, re-running, and the Agent Debugger. |
| [Troubleshooting](troubleshooting.md) | Everyone | The messages you might see, what they mean, and what to do. |
| [FAQ](faq.md) | Everyone | The program, data and security, setup, results, and updates. |
