# Support

This repository holds the public documentation for the **AI Solution Review**. See the
[README](README.md) for what the review is, how it works, and what it requires.

## Where to go for what

| If you want to… | Go here |
|---|---|
| **Request a review for your agent** | Start with your Microsoft account team — your account executive, Cloud Solution Architect, or Customer Program Manager. See [Get started](README.md#get-started). |
| **Ask how the review works** | [Open an issue](../../issues) in this repository. Questions about scope, prerequisites, session format, or data handling are all fair game. |
| **Report an error in these docs** | [Open an issue](../../issues), or send a pull request. See [Contributing](README.md#contributing). |
| **Get help with a live production problem** | Use your normal Microsoft Support channel. This repository is not a support or escalation path, and nobody here is on call. |
| **Report a security vulnerability** | Do not open an issue. Follow [SECURITY.md](SECURITY.md). |

## Before you file an issue

- Search the existing issues first so we don't end up with duplicates.
- **Issues in this repository are public.** Do not post customer or tenant data, environment or
  agent identifiers, conversation transcripts, telemetry exports, screenshots containing real data,
  or anything else confidential. Describe the question generically instead.
- If you are already in a review, raise it with your reviewer in session rather than here — they
  have the context.

## Response expectations

Issues are answered on a best-effort basis by the team that runs the program. There is no service
level agreement, and response times vary.

## Microsoft Support Policy

Support for the AI Solution Review documentation in this repository is limited to the resources
listed above.
